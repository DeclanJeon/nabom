# NABOM Executive Overview v1.0

## 한 줄 정의
나봄은 개인화 굿즈, NFC/QR 페이지, 공동구매, 성장형 디지털 경험을 결합한 커머스 플랫폼이다.

## 핵심 구성
1. Personalized Goods
2. NFC / QR
3. Digital Page
4. Living Profile
5. Group Buy
6. Omnichannel Sales

## 권장 출시 순서
1. SmartStore-first 국내 테스트
2. NABOM 자체 커스터마이징/시안/활성화
3. FIRST 100
4. Unified Order Hub
5. Etsy/Pinkoi 해외 테스트
6. Global Direct Checkout
