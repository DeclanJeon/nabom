# NABOM 브랜드/도메인 결정서

버전: 0.5  
기준일: 2026-08-10

## 최종 결정

- 프로젝트명: **나봄**
- 영문명: **NABOM**
- 메인 서브도메인: **nabom.ponslink.com**
- 내부 핵심 엔진명: **Living Self Engine (LSE)**
- 핵심 문구: **기록할수록 선명해지는 나.**

## 이름의 의미

`나봄`은 다음 의미를 동시에 가진다.

1. 나를 봄
2. 나를 바라봄
3. 과거의 나를 다시 봄
4. 성장하는 나를 발견함
5. 봄처럼 변화하고 확장되는 이미지

## 브랜드 아키텍처

```text
PonsLink
└─ NABOM / 나봄
   ├─ Living Self Engine
   ├─ Weekly Mirror
   ├─ Growth Experiment
   ├─ Living Profile
   └─ NFC Keyring
```

## 사용자-facing 용어

사용:
- 나봄
- 프로필
- 오늘의 나
- Weekly Mirror 또는 이번 주의 나
- 성장 테마
- 작은 실험
- 여정

기본 화면에서 피함:
- 사주
- 팔자
- 일간
- 십성
- 용신
- 대운
- 세운
- 오행 점수

단, 분석 방법 설명에서는 출생정보 기반 전통 명리 체계 사용을 투명하게 알린다.

대표:
