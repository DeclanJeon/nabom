# NABOM 국내·해외 사업 전략 v1.0

기준일: 2026-08-11

## 1. 사업의 본체

나봄은 키링 회사가 아니다.

> **AI 성장 기록 서비스가 본체이고, 키링은 나봄으로 돌아오는 물리적 Portal Object다.**

핵심 퍼널:

```text
물리 상품 구매
→ NFC/QR Activation
→ Profile 001
→ Daily Record
→ Weekly Mirror
→ Growth Experiment
→ 장기 이용/구독
```

따라서 키링 판매량만으로 성공을 판단하지 않는다. 키링을 받은 사용자가 실제로 NFC를 태그하고 7일 뒤에도 기록하며 Weekly Mirror를 보는지가 핵심이다.

## 2. 초기 제품: NABOM Duo Charm

### Memory Charm
개인화 영역.
- 앞면: 사용자의 치비 캐릭터
- 뒷면: 가족, 친구, 연인, 공동체, 반려동물, 중요한 순간의 사진

### Portal Charm
표준화 영역.
- 작은 NABOM 브랜드 참
- NFC 내장 또는 태그 결합
- `https://nabom.ponslink.com/k/{token}`

### Duo 구조를 권장하는 이유
- 양면 개인화와 NFC 제조를 분리할 수 있다.
- NFC 불량이면 Portal만 교체한다.
- Memory Charm만 국가별 트렌드에 맞게 바꿀 수 있다.
- Portal은 대량 표준화 가능하다.
- 향후 키링 유행이 끝나도 Acrylic Stand, Bag Charm, Luggage Tag 등으로 옮겨갈 수 있다.

## 5. 원가 목표

초기 내부 목표 예시:
- Memory Charm: 4,000원 이하
- Portal/NFC: 1,500원 이하
- 포장: 1,000원 이하
- 21일 AI/이미지 비용: 1,500원 이하
- PG: 실제 계약 수수료
- **수작업: 주문당 15분 이하**

중요한 지표는 `Manual Minutes Per Order`다. 제작 원가를 500원 낮춰도 한 주문에 사람이 45분 들어가면 사업은 확장되지 않는다.

## 6. 국내 판매 채널

### 1순위: 자체몰
`nabom.ponslink.com`

역할:
- 가장 높은 마진
- 구매 → Activation → Profile이 한 흐름
- 고객 행동 데이터 직접 측정
- 장기 구독 연결

### 2순위: 네이버 스마트스토어
- 구매 신뢰
- 네이버 검색
- 익숙한 결제 UX

### 3순위: 아이디어스
- 개인화/선물 고객 발견
- 초기 노출 채널

## 7. 해외 판매 채널

### Etsy
Personalized gift 고객획득 채널.
플랫폼 비용이 높아도 시장반응을 빠르게 볼 수 있다.

### Pinkoi
대만 및 아시아 디자인 상품 테스트.

### idus Global
사용 가능 조건이 맞으면 해외운영 부담을 줄이는 실험 채널.

### 자체몰
브랜드와 서비스의 장기 본진.

플랫폼 고객을 정책 위반 방식으로 외부결제로 유도하지 않는다.

## 9. B2C 라인

### FOR ME
나를 위한 기록/성장.

### FOR YOU
생일, 졸업, 기념일, 가족, 연인 선물.

### FOR US
커플, 친구, 가족, 팀, 공동체.

## 10. B2B 라인

타깃:
- 회사 워크숍
- 스타트업 팀
- 대학 동아리
- 졸업
- 여행팀
- 팬/크리에이터 행사
- 교회
- 선교팀
- 청년부
- 각종 커뮤니티

B2B에서는 출생정보/사주를 필수화하지 않는다. 동일한 Living Self Engine에서 onboarding 모듈만 대상에 맞게 변경한다.

## 11. 사업 성공 기준

```text
결제
→ 제품 만족
→ NFC First Tap

→ First Journal
→ Day 7
→ Weekly Mirror Open
→ Next Week Return

→ Subscription
```

각 단계 전환율을 측정한다.

# v1.0 운영 전략 보완

국내/해외 채널은 단순 “입점 목록”이 아니라 단계별 Commerce Architecture로 운영한다.

권장 순서:

```text
Lean Korea:
SmartStore + idus
        ↓
NABOM Customization / NFC Service

Domestic Scale:
SmartStore + NABOM Direct + idus
        ↓
Unified Order Hub

Overseas Test:
Etsy / Pinkoi / idus Global
        ↓
Korea Fulfillment + NABOM Activation

Global Scale:
NABOM Direct Global + Marketplace
```

세부 정책은 `20_Omnichannel_Domestic_Global_Strategy.md`를 기준으로 한다.
