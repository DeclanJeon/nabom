# NABOM 마케팅·영업 Playbook v1.0

## 1. 기본 원칙

광고 하나에서 사주, AI, 일기, 키링, NFC, 성장 기능을 전부 설명하지 않는다.

> **한 콘텐츠 = 하나의 구매 이유**

## 2. 핵심 영상 포맷

### Transformation
```text
실제 사진
→ 치비
→ Memory Charm
→ 뒤집으면 추억 사진
→ Portal NFC Tap
→ Profile 001
```

### AI Hook
“AI가 나를 7일 동안 기억하면 뭘 알아낼까?”

### Emotion
“가족과 찍은 사진을 매일 들고 다니는 방법.”

### Gift
“친구 졸업선물로 세상에 하나뿐인 캐릭터 만들기.”

### Mirror
“내가 생각하는 나 vs 일기 속 실제 나.”

## 10. 영업 방식

긴 회사소개보다:
1. 실제 사례
2. 왜 상대에게 맞는지
3. 20~30초 데모
4. NFC 체험
5. 샘플/견적 CTA

실물을 만나서 보여줄 수 있으면 `Tap → Page` 경험을 먼저 보여준다.

## 11. B2B 상품

### 10~20명
개인 키링 + 단체사진 + 공동 페이지.

### 20~50명
단체 단가.

### Event
행사 기록 페이지 + NFC souvenir.

B2B에서는 출생정보 엔진을 끄거나 선택화할 수 있다.
