# NABOM 커머스·법무·PG·운영 Playbook v1.0

> 실제 신고·세무·법률 판단은 판매 시점의 정부/PG 공식 안내와 전문가 검토를 우선한다.

## 1. 현재 상태
- 개인사업자: 등록됨
- 통신판매업: 미신고
- 자체몰 개발 가능
- PG 직접 연동 가능

## 2. 실행 순서
1. 판매 상품/사업자정보 정리
2. `nabom.ponslink.com` 주문 페이지 준비
3. PG 신청
4. 구매안전/에스크로 관련 서류 확인
5. 통신판매업 신고
6. 이용약관
7. 개인정보처리방침
8. 주문제작 동의
9. 배송/환불/불량 정책
10. 실제 결제 1건 테스트

## 3. 자체몰 최소 기능

### Landing
- 20~30초 제품 영상
- 실물 결과
- NFC 경험
- Profile/Weekly Mirror 맛보기
- 가격
- FIRST 100
- FAQ
- 주문 CTA

### Order
- 상품
- 앞면 사진
- 뒷면 사진
- 닉네임
- 옵션
- 주소
- 주문제작 동의
- 결제

생년월일·출생시간은 결제 전 받지 않는다. 구매 이후 Profile onboarding에서 받는다.

### Post-purchase
- 주문상태
- 치비 시안
- 승인/수정
- 제작
- 배송
- NFC Activation

## 4. PG

초기 검토 1순위 후보:
**Toss Payments**

비교항목:
- 카드
- 간편결제
- 계좌이체
- 해외카드
- 가입비
- 정산주기
- 보증보험
- 에스크로
- 환불 API
- 부분취소
- Webhook

계약 조건은 신청 당시 최신 조건을 기준으로 확정한다.

## 5. 통신판매업

판매 개시 전 정부24/관할기관의 최신 제출요건을 확인한다.

체크:
- [ ] 사업자등록 정보
- [ ] 사이트 URL
- [ ] 구매안전서비스 관련 확인
- [ ] 신고
- [ ] 신고번호 사이트 표시

## 6. 주문제작/청약철회

개인 사진 기반 맞춤제작이므로 구매 전에 다음을 분명히 한다.
- 제작 시작 시점
- 시안 승인 의미
- 수정 횟수
- 단순변심 취소 제한 가능성
- 오제작/불량 처리

“주문제작은 환불 불가” 한 줄로 끝내지 않는다.

## 7. 데이터 분리

### Commerce Data
결제, 주문, 주소, 배송.

### Living Profile Data
출생정보, 일기, 감정, AI 분석.

권한과 접근을 분리하는 것을 권장한다.

## 8. 어린이 타깃

FIRST 100은 성인 중심으로 판매한다.
어린이용 상품으로 명시적으로 판매할 경우 제품안전 관련 요건을 별도 검토한다.

## 9. 국내배송
- 택배비 비교
- Tracking 필수
- 초기에는 무료배송보다 배송비 분리 권장

## 10. 해외배송
- 소형 국제우편/K-Packet 등 검토
- 100g 이하 목표
- 초기 배송비 구매자 부담
- 국가별 관세·세금·제품안전 확인

## 11. 미국/EU

미국과 EU는 규정 변동성과 운영 복잡도가 있으므로 한국/일본 검증 이후 진입한다.
실제 발송 전에 CBP/EU 공식 최신 기준을 다시 확인한다.

## 12. CS 상위 항목
1. NFC 안 됨
2. QR 사용
3. 시안 수정
4. 사진 변경
5. 제품 불량
6. 배송
7. 계정 복구
8. Profile이 안 맞음
9. 데이터 삭제
10. 키링 분실

각 항목별 처리기준과 답변 템플릿을 출시 전에 만든다.
