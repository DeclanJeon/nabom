# NABOM 캐릭터 수동 시각 QA 체크리스트

> 자동 테스트로 검증할 수 없는 시각 품질을 사람이 확인하는 기록용 문서.
> 각 항목에 확인자·날짜·결과(✅ / ❌)를 남긴다. ❌ 항목은 해당 자산만 재생성 후 재확인.

## 대상 자산

- 카탈로그: `frontend/public/characters/stage/` (10 아키타입 × 2 성별 × 10 단계 × 5 상태 = 2,000개)
- 샘플: 20개 원형 × 단계 1·5·10 × 상태 4종 = 최소 240개 눈으로 확인
